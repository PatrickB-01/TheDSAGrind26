# How to solve LeetCode efficiently

For each problem:

1. Read it for 5 minutes.
2. Try solving it for 20–25 minutes.
3. If you're stuck, look at the first hint.
4. If still stuck, study the solution.
5. Close it.
6. Solve it again **without looking**.
7. Revisit it a few days later.

Many people waste time trying to solve every problem completely on their own. Early on, your objective is to learn the underlying patterns, not prove you can reinvent them under pressure.
